# Government Application Job Duties (Master)

Base duty summaries for the "Work Experience" section of government applications (NEOGOV/GovernmentJobs, county/court/district portals).

**How to use:**
- This is the base copy. Keep it general and accurate; update it when a role's duties change.
- When applying, copy this file to `applications/<job-folder>/gov-job-duties.md` and tailor the duties there to match the posting's language and minimum qualifications.
- Pull additional detail from `master/career_inventory.md`. Don't claim anything that isn't backed up there.
- Paste each Duties Summary into the application's duties field. Check the portal's character limit before pasting.

## VCA Consultants Inc.

**Company/Agency:** VCA Consultants Inc.
**Position:** IT Technician II

**Duties Summary:**

Provide IT support and systems administration for a 120-user engineering firm operating across three sites (Los Angeles, Denver, Orange). Primary responsibilities cover the VMware/Omnissa virtual desktop infrastructure used by the entire organization: building and validating instant clone pool images across seven departmental pools, managing VDI application patching, and resolving session issues including profile corruption and Horizon connection latency. Reduced authentication-related help desk requests from several per day to roughly once every week and a half by tuning DEM profile persistence, FSLogix configuration, and login flow.

Administer Active Directory and Entra ID for 120+ accounts, including user provisioning and de-provisioning, group membership reviews, and SSO/MFA/Conditional Access configuration for SaaS applications. Manage Windows endpoints in Intune, maintain hardware inventory across all three sites, and support a 10ZiG thin client fleet centrally managed through a dedicated management server.

Handle LAN/WAN infrastructure including HP Aruba switches, Dell EMC ESXi hosts, TrueNAS storage, and Fortinet firewall rule configuration. Support remote access through Horizon View with DUO authentication. Write and maintain PowerShell and Python automation scripts for recurring IT tasks. Maintain a self-hosted GitLab server and handle backup and disaster recovery procedures for critical VMs and project data.
