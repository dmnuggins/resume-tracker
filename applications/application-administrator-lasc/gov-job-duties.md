# Government Application Job Duties: Application Administrator (LASC)

Tailored copy of `master/gov_job_duties.md` for the Superior Court of Los Angeles County Application Administrator posting. Every addition is backed by `master/career_inventory.md`.

**Tailoring focus:** the posting's duty areas: application configuration, user account administration (least privilege), issue resolution and escalation, vendor/internal support cases, testing and release support, documentation and training aids, health monitoring, and protecting confidentiality, integrity, and availability. The MQ path is Option III (BS CS + 1 year of applications administration), so the VCA and iKrusher entries do most of the work.

**Before pasting:** check the portal's character limit for the duties field and trim from the end of each entry if needed.

## VCA Consultants Inc.

**Company/Agency:** VCA Consultants Inc.
**Position:** IT Technician II

**Duties Summary:**

Provide application administration, IT support, and systems administration for a 120-user engineering firm operating across three sites (Los Angeles, Denver, Orange). Administer the VMware/Omnissa virtual desktop platform used by the entire organization: configure application delivery through App Volumes and the instant clone gold images for seven departmental pools, build and validate every image change on test pools before releasing it to production, and manage application patching (Teams, FSLogix, VMware Tools, Horizon Client) through GPO-controlled update channels. Work with department and team leads to vet new applications before integration, then test and configure them for the VDI environment. Track DEM configuration changes in git for change auditing. Troubleshoot user-reported application issues, including Revit add-ins failing to load due to DEM profile cache corruption and Horizon connection latency. Reduced authentication-related help desk requests from several per day to roughly once every week and a half by tuning DEM profile persistence, FSLogix configuration, and login flow.

Administer user accounts in Active Directory and Entra ID for 120+ users, including provisioning, role changes, and de-provisioning, and enforce least-privilege access across AD and SaaS applications with quarterly group membership reviews. Configure and maintain SSO, MFA, and Conditional Access for business applications including Ajera (ERP), Zoom, Bluebeam, GitHub/GitLab, and Microsoft 365. Standardized account data across AD, Entra ID, and SaaS applications (Autodesk, Bluebeam, Zoom, Ajera) ahead of the Ajera SSO rollout. Configured role-based access control and scoped Microsoft Graph API permissions for an internal application so it could send email only on behalf of a specific user group, instead of granting tenant-wide access. Manage the Microsoft 365 license pool within a 20-seat cap, reassigning license tiers as team needs change. Configured Zoom Booking Pages and call routing attributes stored in AD. Led the consolidation from RingCentral and Teams to Zoom, reducing application management and configuration overhead.

Maintain a self-hosted GitLab server for internally developed code, including upgrading the instance to v19.0.1-ee to enable API integrations. Write and maintain PowerShell and Python automation, including AD user audit reports with terminated-user filtering, and a Python/Microsoft Graph script that generated 700+ SharePoint share links after a 200,000+ file migration. Monitor and triage security alerts in Darktrace, tuning detection to reduce false positives. Write user guides and runbooks, including the Ajera Cloud login and usage guide published to the SharePoint IT library. Support the underlying infrastructure (Dell EMC ESXi hosts, TrueNAS storage, HP Aruba switches, Fortinet firewall rules, Horizon remote access with DUO) and perform backup and disaster recovery for critical VMs and project data.
